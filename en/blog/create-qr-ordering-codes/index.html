How to create QR ordering codes for restaurant tables

A table-ordering QR code only works well if it opens the correct venue menu and identifies the guest’s table. Complete one end-to-end test before printing a code for every table.

Step 1: Prepare the digital menu

List each item, price, a short description and an optional photo. Remove unavailable dishes. Drinks shops should verify how sizes, toppings and special requests are handled.

  • Use clear item names
  • Check prices and availability
  • Compress photos for faster loading

Step 2: Assign a code to each table

Create tables in the management system and generate table-specific codes where supported. Simple table labels such as T01 and T02 make it easier for staff to confirm an order.

  • Scan T01 and verify its identity
  • Check that T02 resolves separately
  • Never expose administrative tokens in a QR URL

Step 3: Print codes that are easy to scan

A tabletop card or sticker can work. Keep good contrast, avoid reflections, and position the code so guests do not accidentally scan a neighbouring table’s code.

  • Print one sample first
  • Test on Android and iPhone
  • Test with mobile data rather than only cafe Wi-Fi

Step 4: Test one complete order

Have a staff member act as a guest: scan, choose items, add a note and submit. Confirm the order appears on the management screen and updates when staff process it.

  • Try more than one device
  • Test connection loss before and after submit
  • Ensure repeated taps do not create duplicate orders

Step 5: Handle future URL changes

If your ordering domain changes, previously printed codes may still point to the old address. Preserve working redirects where possible, including table identifiers and query parameters.
