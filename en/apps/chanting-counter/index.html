Count repetitions on Android or the web, set a goal and save each session so you can review your daily practice over time.

How does a chanting counter work?

  1. Select the chant or mantra for the current session.
  2. Tap to record repetitions and lock the counter when needed to avoid accidental input.
  3. Save the session to review history, goals and progress statistics.

Frequently asked questions

Can the app work without an internet connection?

Yes. Counting and on-device records can be used offline.

Can I review chanting counts by day?

Yes. The app keeps a history and displays daily, weekly and monthly statistics.

Is there a browser version?

Yes. Use the web-version link provided on this page.
